# ROS2-RoboticsLab
Hands-on learning from a college ROS 2 robotics workshop, exploring ROS 2 Humble, TurtleBot3, Gazebo simulation, RViz2 visualization, robot control, topics, nodes, services, LiDAR, TF frames, SLAM mapping, and Nav2 navigation. Includes student-friendly setup instructions, terminal commands, and simulation verification.
